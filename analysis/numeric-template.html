01 / EXACT INTEGER CONTRACT

32비트 넘침과 하위 16비트를 보존한다

{{math}} [C1: arithmetic]

acc = (0x1000 + Σ int16(left[r,k]) × int16(right[k,c])) mod 2^32
out[r,c] = (acc >> 13) & 0xffff

{{alias}} [C2: fixtures·leaf_fixture]

8종 경계 입력 × 8개 배치와 seed 804113의 난수 32사례입니다. 원본·교체본 각각에서 출력 halfword 쓰기 864회를 순서대로 비교했습니다. 입력 겹침으로 달라진 실제 입력을 읽은 뒤 산술 기준값을 계산했습니다. [재구성 C 소스]
