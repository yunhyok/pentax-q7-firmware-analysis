총 복원 크기는 11,266,048 bytes입니다. FAT16의 선언 볼륨 크기는 업데이트 파일보다 크므로 전체 파일시스템이 완전하다고 보지는 않았습니다. 이번에 사용한 세 심볼 파일의 할당 체인과 문자열 경계는 검사했습니다. [S1: geometry, sources]

초기 보고서의 1,504개 FUNC는 ELF 심볼표의 집계입니다. 이번의 122,154개 주소·이름 레코드와 300개 선별 함수는 서로 다른 집합이며 합산하지 않습니다.

05 / JPEG

양자화 계산과 인터럽트까지

{{jpeg}} [S3: ApsCmpRecalcDqt, PathSetJpeg, QtConvert]

{{jpeg_diagram}} 
scale = input_scale & 0xffff
QY[i] = clamp((scale * baseY[i]) >> 14, 1, 255)

QtConvert: inverse-zigzag 순서로 64개 항목 변환
  mode == 1 : 원본 byte를 32비트 항목에 저장
  그 외     : max(1, 0x4000 / source_byte); 0 입력은 trap

StillCaptureImageTuneJpegEnc(0x802de3e0)는 ApsCmpRecalcDqt와 ApsJpegCreate를 호출하지만 Emulation 이름의 입출력 버퍼를 사용합니다. 일반 촬영의 유일한 JPEG 경로로 단정하지 않았습니다. PathSubmit은 경로 타입이 1일 때 JpegPathSubmit을 선택하고 이 함수는 객체 +0x3c4의 비트 0x40이 켜진 경우 IcaPathSubmit을 호출합니다. [S3: 0x801c84bc, 0x801df5a4, 0x802de574, 0x802de728]

{{jpeg_irq}} [S3: IsrJpegDone, JpegPathInit]

ISR의 0x801df628은 호출, 0x801df644는 꼬리 점프입니다. 대상은 둘 다 _tx_isr_suspend이며 인자는 각각 0x801e3890, 0x815a1d6c입니다. 등록은 확인했지만 실기에서 인터럽트가 발생했는지는 검사하지 않았습니다.
