PENTAX Q7 · 펌웨어 1.01

Q7 펌웨어를 풀어 본 기록

리코가 배포한 펌웨어 파일에서 프로그램을 꺼내 압축을 풀고, 카메라가 업데이트를 설치하고 색을 처리하고 초점을 맞추고 메뉴 글자를 그리는 코드를 추적했습니다. 무엇을 알아냈고 무엇은 아직 모르는지 근거와 함께 적었습니다.

먼저 알아 둘 점

모든 분석은 PC에서 했습니다. 수정한 펌웨어를 카메라에 설치하거나 실행한 적이 없습니다. 이 저장소에는 카메라에 넣을 수 있는 펌웨어가 없으며, 원본 펌웨어와 거기서 꺼낸 프로그램·심볼 목록·디컴파일 원문도 들어 있지 않습니다.

이 연구가 답하려는 네 가지 질문

세 기종(K-3 Mark III, K-3 II, Q7)을 같은 질문으로 조사하고 있습니다. 아래는 Q7에서 지금까지 온 지점입니다. 세 기종을 나란히 비교한 표는 세 기종 연구 본부에 있습니다.

  • 목표 1

    펌웨어를 고쳐서 다시 만들 수 있는가

    파일을 다시 만드는 단계까지 확인

    알아낸 것
    압축 블록 {{block_total}}개를 풀었다가 다시 압축하면 배포본과 바이트까지 같습니다. 색 행렬 함수 하나를 C로 다시 짜서 원래 자리에 넣은 파일도 만들었습니다. 업데이트를 설치하는 코드의 앞부분을 따라갔습니다.
    아직 모르는 것
    카메라가 수정한 파일을 받아들이는지, 부팅하는지. 내부 저장장치(NAND)에 실제로 기록되는 과정.
  • 목표 2

    카메라의 색은 어떻게 만들어지는가

    색 설정이 하드웨어로 가는 경로를 추적

    알아낸 것
    색 행렬이 영상 처리 회로의 레지스터로 전달되는 조건과, HDR 촬영에서 마지막 처리 단계가 정해지는 과정을 추적했습니다.
    아직 모르는 것
    실제 픽셀이 처리된 결과. 일반 촬영과 HDR의 색 처리 차이. Lightroom 프로파일이 카메라 색에 얼마나 가까운지.
  • 목표 3

    AF 동작을 바꿀 수 있는가

    제어 코드를 읽는 기초 단계

    알아낸 것
    렌즈에 명령을 보내고 응답을 받는 흐름을 확인했습니다. “명령이 성공했다”와 “렌즈가 움직임을 마쳤다”를 펌웨어가 따로 판정한다는 점을 구분했습니다.
    아직 모르는 것
    실제 렌즈와의 통신, 모터 이동, 초점 정확도. 코드를 바꿔 본 적은 없습니다.
  • 목표 4

    K-3 Mark III의 화면을 이 기종에 옮길 수 있는가

    이 기종이 화면을 그리는 방식을 분석한 단계

    알아낸 것
    색공간 메뉴 화면 하나를 골라 선택·확정·취소부터 글꼴 파일을 읽어 글자 픽셀을 찍는 단계까지 따라갔습니다.
    아직 모르는 것
    실제 버튼 입력에서 LCD 출력까지의 연결과 실제 색. 화면을 옮기는 작업은 시작하지 않았습니다.

펌웨어 파일 안에 든 것

배포 파일 fwdc603p.bin에는 실행 파일 형식(ELF)으로 된 프로그램 {{elf_count}}개가 들어 있습니다. 모두 32비트 MIPS용입니다. 아래 막대는 파일 안에서 각 프로그램이 차지하는 위치입니다.

  • {{input_size}}바이트배포 파일 크기
  • {{elf_count}}개내장 ELF (32비트 MIPS)
  • {{block_total}}블록본 프로그램의 압축 블록
  • ThreadX · FileX식별 문자열로 남은 RTOS와 파일시스템
  • {{release_date}}펌웨어 1.01 공식 배포일

어떤 프로그램들인가

  • 카메라 본 프로그램 (E03–E06) — 촬영, AF, 영상 처리, 메뉴. E04–E06은 압축되어 있어 {{block_total}}블록을 풀어 {{decoded_total}}바이트를 복원한 뒤 분석했습니다.
  • 업데이트 로더 (E01) — 펌웨어 업데이트를 맡는 별도 프로그램. RTOS인 ThreadX와 파일시스템 FileX의 심볼 이름이 남아 있습니다.
  • 그 밖의 작은 ELF — 용도를 따로 조사하지 않았습니다.

다른 두 기종과 무엇이 다른가

K-3 계열은 ARM 프로세서를 쓰지만 Q7의 프로그램은 MIPS용입니다. 파일 형식도 달라서 K-3 Mark III의 압축 해제 도구는 Q7에 그대로 통하지 않습니다. 그래서 주소와 함수의 의미를 다른 기종에서 가져오지 않고 이 파일에서 따로 확인했습니다.

식별 문자열과 심볼만으로 실제 칩의 모델을 확정할 수는 없습니다. 칩 모델은 확인하지 못했습니다.

검증 수준 읽는 법

모든 문서는 결과마다 “얼마나 확실한가”를 같은 네 가지 표시로 구분합니다. 표시가 다르면 믿을 수 있는 정도가 다릅니다.

  • 확인

    원본 펌웨어의 기계어를 PC의 CPU 에뮬레이터에서 실제로 실행해 관측했거나, 파일의 바이트를 직접 읽어 구조와 해시를 대조한 결과입니다.

  • 정적 분석

    코드를 실행하지 않고, 기계어를 사람이 읽을 수 있게 바꾼 결과를 읽어서 판단한 내용입니다.

  • 모델

    하드웨어의 응답이나 입력 데이터처럼, 실물 대신 연구자가 정해서 넣은 값입니다. 그 조건에서만 성립합니다.

  • 미확인

    아직 확인하지 못했거나, 실물 카메라가 있어야 확인할 수 있는 내용입니다.

이 기종의 RAW로 한 Lightroom 색 프로파일 실험은 성격이 다릅니다. 실제 RAW 파일을 실제 Adobe Lightroom Classic에 넣어 얻은 측정값이며, K-3 Mark III 저장소의 Lightroom 색 프로파일 문서에 세 기종을 함께 정리했습니다.

공개된 문서·근거 파일·도구가 서로 맞는지 검사합니다. Python 3.10 이상과 표준 라이브러리만 있으면 됩니다.

python -m unittest discover -s tests -v
python tools/pentax_lz.py --self-test
python tools/verify_report.py

펌웨어 파일을 가지고

리코 공식 사이트에서 받은 fwdc603p.bin(SHA-256이 아래와 같은 파일)이 있으면 공개한 측정값 전체를 다시 계산해 비교할 수 있습니다.

python tools/inspect_q7.py fwdc603p.bin --output .private/recheck.json --private-dir .private/recheck-elf
python tools/verify_report.py --firmware fwdc603p.bin
