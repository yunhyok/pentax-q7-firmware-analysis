Custom Image 색 엔진 표와 계산

Q7 펌웨어 1.01 본 프로그램(E04)에서 Custom Image의 색과 밝기를 결정하는 숫자 표 {{TOTAL_TABLES}}건을 추출하고, 다섯 루틴의 정수 계산과 9×9×9 3차원 표 보간을 카메라 JPEG와 대조했습니다.

이 문서에서

  1. E04에서 추출한 색 엔진 표
  2. 다섯 루틴과 9×9×9 3차원 표 경로
  3. Custom Image 기본값과 Reversal Film 화이트밸런스
  4. 실물 사진·에뮬레이터 검증 요약
  5. 근거 파일과 참고 자료

핵심 요약

  • E04 세그먼트에서 색 행렬·톤 곡선·조색 오프셋·채도 억제·Custom Image 기본값 기록 등 {{TOTAL_TABLES}}건을 추출했습니다(analysis/color-engine-tables.json).
  • MakeColorMatrix(276건), CalcGammaCorrectionTable과 Reversal(1,636건), CalcBasicGammaCorrectionTable·MakeColorReproductionLutParam(794건)을 Unicorn MIPS 에뮬레이터로 돌려 파이썬 이식과 전수 일치를 확인했습니다.
  • Q7은 색 행렬과 감마를 따로 적용하지 않고 CalcBasicGammaCorrectionTable(표 D)로 9×9×9 3차원 색 재현 표의 격자 입력을 정합니다. 실물 DNG 한 장의 카메라 JPEG 10종과 비교하면 사면체 보간과 하이라이트 채도 억제를 넣었을 때 24패치 평균 ΔE76 0.97~1.43으로 맞습니다.
  • Reversal Film(모드 6)만 화이트밸런스 기본 기록의 InnerModeLimitation이 0이라 Auto 화이트밸런스에서도 태양광 분류(1번)로 계산됩니다.

확인 표 추출과 에뮬레이션으로 확인한 것

  • E04 내 색 표 {{TOTAL_TABLES}}건의 주소·크기·값
  • 정수 루틴 다섯 개의 에뮬레이션 대조(276 / 1,636 / 794건 모두 일치)
  • DNG ColorMatrix 1·2 및 AdobeRGB 변환 행렬의 펌웨어 값 일치

정적 분석 코드 읽기로 확인한 것

  • 9×9×9 3차원 표 생성과 R·G·B 크기 순서 6구역 행렬 분기
  • SetupWhiteBalanceUnit·CWhiteBalanceService_vCalclation의 Reversal 예외 경로

모델 사진 비교·하드웨어 모델 가정

  • 사면체 보간 방식과 평상시 감마 기준값(v = 512)
  • 하이라이트 채도 억제 기울기 (255 − 밝기) / 55(시작점 200은 펌웨어 표)

미확인 확인하지 않은 것

  • Cross Processing(모드 9·10의 채널별 감마 B·C)의 전체 톤 곡선 생성 규칙
  • 고감도·하이라이트/섀도 보정 켜짐 상태에서의 +0x164·+0x174 동적 변화

다섯 루틴과 9×9×9 3차원 표 경로

Q7은 기본 감마(표 D)를 하드웨어 감마 블록에 넣고 그 출력을 9×9×9 3차원 표의 격자 인덱스로 씁니다.

  • 색 행렬 여섯 개: MakeColorMatrix(0x8041c180)가 채도 × MakeUp6[i] × CameraBasic을 32로 나누고 대각 성분을 행의 합 256에 맞추어 저장합니다.
  • 서술자 A·B(CM·FC1): 서술자 A(+0x18)는 단위행렬 기반 이득 행렬이고 서술자 B(FC1)는 HueShift × YCbCr(AdobeRGB면 arcnsSRGBAdobeRGB 곱)에 조색 Cb·Cr 오프셋을 0x800 더해 넣습니다.
  • 일반 감마 · 리버설 · 기본 감마: CalcGammaCorrectionTable(0x8041d058)은 128..2048 5개 열 256점 가운데 앞 129점(0..128)을 쓰고 위쪽은 직선으로 잇습니다. CalcBasicGammaCorrectionTable(0x8041d7e8)은 고정 대비(−7, −4, −6)로 256점을 모두 써서 표 D를 만듭니다.
  • 3차원 표(0x8041c7dc): 표 D가 처음 0, 512, …, 4095에 닿는 입력 9점을 축마다 골라 729점에서 RGB 크기 순서 행렬, YCbCr 변환, arwCChromaSuppressionRatioLut 암부 억제, 표 A 조회를 순서대로 실행합니다.

Custom Image 기본값과 Reversal Film 화이트밸런스

펌웨어 기본값 기록(cntCustomImageUnit*)과 DNG 메이커노트 값이 0..8(가운데 4 = 0) 부호화까지 일치합니다.

{{UNIT_ROWS}}
주요 Custom Image 출고 기본값 (설정은 −4..+4, 저장값은 4가 0)
모드ID채도대비샤프니스키색상조색 색

m_arpcPictureArrangeParameter(0x804457a8)에서 6번 Reversal Film만 cntWhiteBalanceReversal(InnerModeLimitation = 0, InnerMode = 1)을 씁니다. 따라서 Auto 화이트밸런스를 골라도 CWhiteBalanceService_vCalclation이 태양광 분류(1번)로 돌려 계산합니다.

실물 사진·에뮬레이터 검증 요약

ColorChecker Classic DNG 한 장을 카메라에서 10종 Custom Image로 다시 현상한 JPEG와 비교한 결과, 사면체 보간과 하이라이트 채도 억제를 함께 적용했을 때 24패치 평균 ΔE76은 0.97(Muted·Monochrome)에서 1.43(Bleach Bypass Green) 사이로 측정되었습니다.

루틴별 세부 계산식과 JPEG 패치별 오차 표 원문은 docs/color-engine-tables.md에 있으며 이식 코드와 에뮬레이터 대조 스크립트는 firmware-color-studio의 q7_engine.py·tools/q7/check_port.py에서 유지합니다.
