# v0.4.0 — 새 보고서 검수와 문장 다듬기

v0.3.x에서 올라온 보고서를 검수해 다른 보고서와 같은 형식으로 다시 쓰고, 사이트 전체의 문장을 다듬은 릴리스입니다. 새로운 분석 결과는 없습니다.

문서: https://yunhyok.github.io/pentax-q7-firmware-analysis/

## 바뀐 것

- **새 보고서 7쪽을 다시 썼습니다.** NAND 저장장치 4쪽(`nand-header-report`, `reports/nand-boot-read`, `reports/nand-context`, `reports/nand-filex`), DCP 파일 분석 2쪽(`reports/q7-dcp-structure`, `reports/q7-dcp-interpolation`), `colorspace-clip-report`입니다. 요약과 확인한 범위를 맨 앞에 두고, 배경 설명과 그림을 넣고, 주소·해시는 접어 두었습니다.
- **안내 문서를 갱신했습니다.** 업데이트, 색 처리, 화면 안내의 지도, 현황 표, 읽는 순서에 새 보고서를 넣었습니다. DCP 파일 분석은 펌웨어의 색 처리 경로와 구분해 따로 묶었습니다.
- **모든 보고서의 문장을 다듬었습니다.** 한국어 윤문 규칙에 따라 연결어미 뒤 쉼표를 빼고, 긴 문장을 나누고, 에두른 표현을 직접 서술로 바꿨습니다. 수치·주소·코드는 바꾸지 않았고, 고친 문단마다 기계로 확인했습니다.
- **표와 그림을 빌더가 만듭니다.** 새 보고서의 표, 합계, 일부 그림은 빌더가 근거 JSON에서 만듭니다. 템플릿에 적은 숫자가 근거와 다르면 생성이 멈춥니다.
- **용어집에 새 용어를 넣었습니다.**

모두 34쪽, 그림 81개입니다. 보고서의 파일 이름과 주소는 그대로입니다.

## 검수에서 고친 것

수치·주소·해시에서는 오류를 찾지 못했습니다.

- `reports/nand-context.html`의 깨진 문서 구조를 다시 짰습니다.
- DCP 보고서 두 쪽의 "~다"체를 합쇼체로 바꾸고, 본문 뒤에 있던 한계를 요약으로 올렸습니다. 이 보고서들은 프로파일 파일의 구조와 계산을 다루며, 카메라 색을 재현한다는 근거가 아닙니다.
- `reports/nand-filex.html`에 필드를 읽는 명령의 정확한 위치(지연 슬롯)를 보탰습니다.
- 다른 문서를 "앞선 분석"처럼 가리키던 표현을 문서 이름으로 바꿨습니다.

전체 목록과 판단이 필요한 항목은 [`docs/audit/2026-11-second-review.md`](https://github.com/yunhyok/pentax-q7-firmware-analysis/blob/main/docs/audit/2026-11-second-review.md)에 있습니다.

## Lightroom 색 프로파일은 넣지 않았습니다

이 릴리스에 카메라 색 프로파일은 없습니다. Q7용 후보는 공개 DNG의 태그에서 행렬을 옮겨 적은 시험 프로파일 하나입니다. 스튜디오 장면 한 장에서 Adobe Standard보다 카메라 JPEG에 가까웠지만(픽셀 ΔE00 중앙값 2.211 대 2.803), 이미지 전체의 위치 맞춤이 기준을 넘겨 일부 영역만 비교했고 두 결과의 화이트밸런스도 달랐습니다. 장면과 조명은 하나이고 표본의 펌웨어 버전도 분석 대상과 다릅니다. 자세한 근거는 [Lightroom 색 프로파일 안내](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/guide-lightroom.html)에 있습니다.

## 알아 둘 점

- 검수는 원본 펌웨어 없이 했습니다. 문서가 공개된 근거 JSON·검사 스크립트와 맞는지 확인했고, 검사 스크립트를 펌웨어에 다시 돌리지는 않았습니다.
- 근거 JSON과 검사 스크립트는 고치지 않았습니다.
- 이 저장소에는 여전히 원본 펌웨어, 거기서 꺼낸 프로그램, 카메라에 넣을 수 있는 펌웨어가 없습니다. 모든 분석은 PC에서 했습니다.

## 내려받기
