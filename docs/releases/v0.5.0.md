# v0.5.0 — Custom Image 색 엔진 HTML 보고서와 Q 마운트 렌즈 펌웨어 검증

원본 본체 펌웨어(`fwdc603p.bin`)와 실제 배포된 Q 마운트 렌즈 펌웨어(`fwlq101.bin`, `fwlq102.bin`)를 다시 대조하고, `docs/color-engine-tables.md`로만 있던 Custom Image 색 엔진 연구와 신규 렌즈 업데이트 검증을 정적 HTML 보고서로 통합한 릴리스입니다.

문서: https://yunhyok.github.io/pentax-q7-firmware-analysis/

## 추가·갱신한 것

- **Q 마운트 렌즈 펌웨어 검증 보고서 (`reports/lens-firmware-update.html`)**: 본체 펌웨어 `LensFirmwareUpdateService_GetCrc_BYTE`(`0x807dceec`)와 `UserLensFirmwareUpdateExecutionCheck`(`0x807dcf48`)를 MIPS32LE Unicorn 에뮬레이터에서 실행해 `fwlq101.bin`(01 STANDARD PRIME) 및 `fwlq102.bin`(02 STANDARD ZOOM)과 대조했습니다.
  - 파일 끝 2바이트 CRC-16/CCITT(`0x1ca0`, `0x1f20`)과 헤더 `0x30` LOM 본문 CRC(`0x2668`, `0xfea2`)가 에뮬레이션 출력과 정확히 일치합니다.
  - 정상 2건 및 ID 불일치·파일 CRC 1비트 손상·체크 바이트 오류·열기 실패 4건을 포함한 6사례를 `analysis/lens-firmware-update.json`과 `tests/test_lens_firmware_update.py`로 고정했습니다.
- **Custom Image 색 엔진 HTML 보고서 (`reports/color-engine-tables.html`)**: `analysis/color-engine-tables.json`(12개 범주 123건)과 `docs/color-engine-tables.md`의 5루틴·3D LUT·실물 JPEG 10종 비교·Reversal Film 화이트밸런스 결과를 정적 문서 사이트에 편입했습니다.
- **펌웨어 전체 재검증 감사 기록 (`docs/audit/2026-11-firmware-verification.md`)**: `fwdc603p.bin`, `fwlq101.bin`, `fwlq102.bin` 대상 재검증 결과를 기록했습니다.

## 알아 둘 점

- 기존 릴리스와 마찬가지로 원본 펌웨어 바이너리, 복원한 ELF, 전체 심볼 테이블, 디컴파일 원문은 저장소에 포함하지 않습니다.
- `analysis/hq-status.json` 내 기존 `stable_evidence` 해시 계약은 그대로 유지했습니다.

## 내려받기

`pentax-q7-firmware-analysis-v0.5.0.zip`에 문서 사이트와 검증 도구 전체가 들어 있습니다. 압축을 풀고 `index.html`을 브라우저로 열 수 있으며 `SHA256SUMS.txt`로 파일 무결성을 검증할 수 있습니다.
