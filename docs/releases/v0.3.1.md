# v0.3.1 — Q7 DCP 보간 규칙과 재현 도구

고정된 Q7 Adobe Standard DCP의 HueSat 표 두 개와 Look 표에 대한 보간 규칙을 공개합니다. SDK 원본 소스와 대조한 15개 합성 HSV 사례를 다시 계산했으며, 공개 CLI의 결과가 작성자 기록과 바이트 단위로 일치했습니다. 전체 테스트 121개와 문서 검증이 통과했습니다.

- HueSat 표는 4개 이웃, Look 표는 8개 이웃을 사용합니다. 값 축이 하나여도 valueScale은 적용하며, 인코딩 태그가 없을 때의 선형 기본값을 항등 LUT로 해석하지 않습니다. binary64와 50자리 Decimal 모형의 사례별 최대 차이는 약 1.95×10⁻¹⁴였습니다. [도식과 분석](https://yunhyok.github.io/pentax-q7-firmware-analysis/reports/q7-dcp-interpolation.html)
- 다음 과제는 실제 SDK의 real32 계산과 두 illuminant 표의 백색점 혼합을 대조한 뒤, 고정 RAW의 렌더링 및 Lightroom 출력으로 범위를 넓히는 것입니다. 이번 릴리스의 보간 모형은 RAW·Lightroom 전체 렌더 검증이 아닙니다.
- 중단된 NAND 후속 실행은 재시도하지 않았습니다. 독립적인 DCP 색 연구를 이어갔으며, 물리 NAND 보존·복구·부팅과 수정 펌웨어 수용은 미검증입니다. [전체 연구 현황과 다음 과제](https://yunhyok.github.io/pentax-k3iii-firmware-analysis/analysis/research-program.html)

ZIP에는 v0.3.0의 기존 분석과 새 재현 코드·문서가 들어 있습니다. 원본 펌웨어, 상용 DCP 전체 표와 Adobe SDK 원문은 포함하지 않습니다. 별도 입력으로 재현하며 ZIP의 무결성은 함께 제공하는 SHA256SUMS.txt로 확인할 수 있습니다.
